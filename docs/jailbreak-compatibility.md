# Kindle 越狱兼容性记录

## 1. Device

- Device model: Kindle 11th Generation, 2024 Release
- KindleModding device code: KT6
- Firmware: 5.19.6

## 2. Current Compatibility Status

当前不能确认 **KT6 + 5.19.6** 这一设备与固件组合已经获得 Véra 的直接支持。

当前状态是等待进一步确认实际支持情况，不执行任何越狱操作。

## 3. What Is Confirmed

- Véra 官方文档说明，部分固件版本为 `<=5.19.6` 的新设备支持仍处于未来移植状态。因此，不能仅凭固件版本判断设备可以越狱。
- 如果当前固件没有兼容的越狱方法，未越狱设备不能先通过降级来获取旧版越狱。
- 越狱的作用是让 Kindle 能够运行外部代码，例如 KOReader；它不等于更换整个操作系统。
- 当前应继续保持飞行模式，避免设备自动升级。

## 4. What Is Not Yet Confirmed

- Véra 是否已经在 KT6 + 5.19.6 这一具体组合上获得官方明确支持与稳定验证。
- 在该设备与固件组合上执行越狱的实际可行性与风险。

## 5. Current Action

- 继续保持飞行模式，避免自动升级。
- 等待并进一步核实 **KT6 + 5.19.6** 的实际支持状态。
- 在兼容性得到明确确认之前，不执行任何越狱操作。
